      Azure OpenAI not configured

      Copy .env.example to .env and set the four VITE_AZURE_OPENAI_* variables (endpoint, deployment, api version, key), then restart the dev server.

      You can still walk around, but the characters won't talk until Azure OpenAI is configured.
